# Milestone 2: OAuth & Cloud Union Management Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Connect Baulr to real cloud providers (Google Drive and Microsoft OneDrive) via Rclone loopback JSON-RPC, automatically maintain a unified storage pool (`baulr_vault:` with `mfs` write policy), expose real-time capacity telemetry, and enable frictionless account connection and disconnection.

**Architecture:** A thin Rust Backend-For-Frontend (BFF) communicates with the persistent `rclone rcd` daemon over loopback HTTP JSON-RPC. OAuth flows are initiated via Rclone's `/config/create` endpoint, listening on `127.0.0.1:53682` and opening the user's browser without credential prompts. A virtual union remote (`baulr_vault:`) is automatically reconfigured upon account changes to aggregate available free space. Real telemetry from `/operations/about` and `/config/dump` replaces mock data in the frontend.

**Tech Stack:** Tauri v2, Rust (Tokio, reqwest, serde, tauri-specta), Rclone Remote Control (RC) JSON-RPC, React 19, TypeScript, Zustand, Tailwind CSS v4, Vitest, React Testing Library.

## Global Constraints
- **Zero-Panic Invariant:** Prohibit `.unwrap()` and `.expect()` in Rust production code (`.agents/rules/tauri-rust.md`).
- **Persistent Daemon Only:** Zero one-off CLI execs; all actions executed via HTTP JSON-RPC on loopback (`.agents/rules/rclone.md`).
- **Strict IPC Boundary:** Frontend components never invoke Tauri directly; all calls routed through `src/lib/api/` consuming `src/lib/bindings.ts` (`.agents/rules/frontend.md`).
- **File & Component Sizing:** Modular React components strictly under 150 lines; Rust modules under 200 lines.
- **Copy Standards:** Strictly adhere to `RULE[user_global]` — no backend jargon (`hash`, `checksum`, `endpoint`, `payload`, `remote copies`); use clear product copy (`Cloud`, `Account`, `Saved`, `Safely backed up`).

## User Review Required

> [!IMPORTANT]
> **Built-in OAuth Credentials (Default)**: Rclone bundles official OAuth client credentials for Google Drive and Microsoft OneDrive, enabling zero-touch browser sign-in for users without requiring them to set up a Google Cloud Console or Microsoft Azure developer portal project. We will use these default configurations.
>
> **Vault Storage Isolation**: Upstream remotes will target a dedicated subfolder on each provider (`gdrive:BaulrVault` and `onedrive:BaulrVault`) to prevent cluttering the user's root cloud directory.
