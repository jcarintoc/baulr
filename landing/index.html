Baulr

Local-first desktop vault that unifies free cloud storage into one virtual drive and safely offloads local files.

Download Baulr

🍏 Download for macOS (Apple Silicon) .dmg (32 MB) 🪟 Windows (x64) & All Releases GitHub Releases

macOS Installation: Download the .dmg, double-click to open, and drag Baulr into your Applications folder. Compatible with macOS 11.0 (Big Sur) and later.

Unified Free Storage

Pools Google Drive (15 GB) and OneDrive (5 GB) accounts into a seamless virtual vault with automatic capacity routing.

Verified Safe Backup

Automatically checks file integrity against cloud checksums before prompting to free up local disk space.

Non-Destructive Cleanup

Reclaiming space moves local copies to your computer's Trash/Recycle Bin. Your files are never permanently deleted.

100% Local-First

Direct encrypted communication with cloud providers over loopback. No middleman servers or third-party tracking.

Baulr is open source. View source code and release history on GitHub.
