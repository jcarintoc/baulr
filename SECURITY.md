# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within Baulr, please **do not open a public issue or discussion**.

Instead, report it directly via email to:
**carlotaarintoc@gmail.com**

Please include in your report:
- A clear description of the issue and potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the vulnerability.
- Any suggested fixes or remediations.

We take security issues seriously and will respond promptly to acknowledge receipt and coordinate a resolution.
